The repository is split into two cooperating services: `extension/` implements a browser-side scanner (content script + service worker) that inspects visited pages, titles, and links then forwards them over HTTP to the backend at `http://127.0.0.1:8000/scan_links`; `backend/` exposes a FastAPI server (Uvicorn on port 8000) that runs a two-stage pipeline of rule-based heuristics followed by an Alibaba DashScope OpenAI-compatible call to `qwen3.7-plus`, returning structured JSON risk scores of Safe, Suspicious, or Dangerous. The extension must be loaded as an unpacked extension in Chrome/Edge developer mode only after the backend is running, and an evaluation script (`evaluate_engine.py`) inside `backend/` drives automated accuracy testing against a known dataset by hitting the same API endpoints. The data flow is strictly one-way: browser → service worker → FastAPI; the backend has no knowledge of the extension beyond the shared `/scan_links` contract.
