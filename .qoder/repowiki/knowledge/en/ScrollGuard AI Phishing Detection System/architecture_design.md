The project is split into two cooperating services: the `extension/` directory implements a browser-side scanner that inspects visited pages, titles, and links, then forwards them to the local backend; the `backend/` directory exposes a FastAPI server (Uvicorn on port 8000) that calls the DashScope OpenAI-compatible API (`qwen3.7-plus`) and returns structured JSON risk scores of Safe, Suspicious, or Dangerous. The extension and backend communicate over HTTP to `http://127.0.0.1:8000`, so the backend must be running before the extension can perform scans. An evaluation script (`evaluate_engine.py`) in `backend/` drives automated accuracy testing against a known dataset by hitting the same API endpoints.
