The repository is split into two cooperating services: `extension/` implements a browser-side scanner that inspects visited pages, titles, and links then forwards them over HTTP to the local backend at `http://127.0.0.1:8000`; `backend/` exposes a FastAPI server (Uvicorn on port 8000) that runs a two-stage pipeline of rule-based heuristics followed by an Alibaba DashScope OpenAI-compatible call to `qwen3.7-plus`, returning structured JSON risk scores of Safe, Suspicious, or Dangerous. The extension must be loaded as an unpacked extension in Chrome/Edge developer mode only after the backend is running, and an evaluation script (`evaluate_engine.py`) inside `backend/` drives automated accuracy testing against a known dataset by hitting the same API endpoints.
