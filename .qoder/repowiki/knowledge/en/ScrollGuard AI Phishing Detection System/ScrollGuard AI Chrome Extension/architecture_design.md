Flat four-file Chrome Manifest V3 package declaring three execution contexts in `manifest.json`: a background service worker (`background.js`) registered under `background.service_worker`, a content script (`content.js`) injected at `document_idle` into `<all_urls>`, and a popup UI (`popup.html` + `popup.js`) bound via `action.default_popup`. The content script runs on page load and throttled scroll events, extracting all `http*` anchor hrefs and forwarding them to the background service worker through `chrome.runtime.sendMessage({ action: 'scanPageLinks', links })`. The background service worker acts as a privileged proxy, POSTing the link array to `http://127.0.0.1:8000/scan_links` and returning JSON results (status/score) back to the caller; it returns `true` from the message listener to keep the channel open for async responses. Results are applied by styling matching anchors with colored bottom borders and setting a tooltip title. The popup independently queries the active tab URL via `chrome.tabs.query` and reuses the same `scanPageLinks` message path to render per-link status cards. Permissions declared are `activeTab`, `scripting`, and `storage`; host permission is `<all_urls>` to allow the background worker to reach the local backend.
