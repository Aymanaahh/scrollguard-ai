Flat four-file Chrome Manifest V3 package declaring three execution contexts in `manifest.json`: a background service worker (`background.js`) registered under `background.service_worker`, a content script (`content.js`) injected at `document_idle` into `<all_urls>`, and a popup UI (`popup.html` + `popup.js`) bound via `action.default_popup`. The content script runs on page load, extracts all `http*` anchor hrefs (filtering out same-origin, non-HTTP schemes, and SPA stubs), deduplicates them with a `Set` of scanned URLs plus a `WeakSet` of processed anchors, and batches them to the background service worker through `chrome.runtime.sendMessage({ action: 'scanPageLinks', links })`. A `MutationObserver` on `document.body` watches for newly inserted nodes and re-scans only new links every 300 ms. The background service worker is the privileged proxy that POSTs the link array to `http://127.0.0.1:8000/scan_links` and returns JSON results back to the caller; it returns `true` from the message listener to keep the channel open for async responses. Results are applied by the content script via inline DOM mutation (`element.style.outline`, `backgroundColor`, badge insertion) and by the popup which independently queries the active tab URL via `chrome.tabs.query` and reuses the same `scanPageLinks` message path to render per-link status cards.
