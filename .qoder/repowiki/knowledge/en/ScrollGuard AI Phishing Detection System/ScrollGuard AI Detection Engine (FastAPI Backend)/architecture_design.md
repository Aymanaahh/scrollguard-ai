Single-file FastAPI application in `main.py` exposing two routes: a health check at `/` and an `/analyze` POST endpoint that accepts `AnalysisRequest` (url, text, platform) and returns an `AnalysisResponse` (status, risk_score, explanation, flagged_reasons). The server constructs a system prompt (`SYSTEM_PROMPT`) enforcing strict JSON output, then delegates classification to the Qwen model via the OpenAI-compatible client pointed at `https://dashscope-intl.aliyuncs.com/compatible-mode/v1`. CORS is enabled with permissive origins to allow browser-extension clients. Configuration is loaded from `.env` via `python-dotenv`, requiring `DASHSCOPE_API_KEY`. Supporting scripts: `evaluate_engine.py` iterates over `scam_dataset.json` and posts each sample to the running server to compute accuracy against `expected_status`; `test_qwen.py` is a standalone connectivity test for the Qwen API.
