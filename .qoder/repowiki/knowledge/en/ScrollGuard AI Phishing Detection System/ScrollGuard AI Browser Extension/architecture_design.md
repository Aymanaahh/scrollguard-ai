A minimal Chrome extension (manifest v3) composed of four files with two distinct execution contexts. `content.js` is injected into every page (`matches: <all_urls>`, `run_at: document_idle`) and performs client-side heuristic scanning against two static lists — `URL_INDICATORS` (suspicious TLDs, URL shorteners, phishing path keywords, hyphen-heavy domains) and `TEXT_INDICATORS` (regex patterns for prize scams, crypto investment fraud, urgency/credential harvesting). When matches are found it builds an inline DOM banner (`__scrollguard_banner__`) with severity labels (POTENTIAL THREAT / SUSPICIOUS / HIGH RISK) based on hit count and injects it at the top of `<body>`. The popup UI (`popup.html` + `popup.js`) is declared as the extension action's default popup; it reads the active tab URL via `chrome.tabs.query` and sends a POST to `http://127.0.0.1:8000/analyze` with `{url, text, platform}` to fetch a scored risk assessment from a local Uvicorn server, then renders status, risk score, and explanation. There is no background script — communication between content script and popup does not occur; they operate independently.
