Single-process FastAPI application (`main.py`) exposing three HTTP endpoints: `GET /` health check, `POST /analyze` for single URL+text analysis returning an `AnalysisResponse`-compatible dict, and `POST /scan_links` accepting a `URLBatch` and processing URLs concurrently with `asyncio.gather`. Each classification follows a fixed two-stage pipeline implemented in `_analyze_single_url`: first `heuristics.heuristic_scan()` runs rule-based checks (free TLDs, URL shorteners, deep subdomains, hyphen-heavy domains, typosquatting regex, scam keywords in path/domain, missing HTTPS) to short-circuit with a non-Safe result; if the heuristic returns Safe, the request is forwarded to an `AsyncOpenAI` client targeting Alibaba DashScope's OpenAI-compatible endpoint at `https://dashscope-intl.aliyuncs.com/compatible-mode/v1` using model `qwen3.7-plus`, rate-limited by a module-level `asyncio.Semaphore(5)`. A module-level `SYSTEM_PROMPT` enforces strict JSON output matching the response schema, and raw LLM responses are post-processed by stripping markdown code fences before `json.loads`. Configuration is bootstrapped via `python-dotenv` loading `.env`, which must contain `DASHSCOPE_API_KEY`; CORS is enabled with wildcard origins. Supporting scripts form a separate evaluation layer: `evaluate_engine.py` posts all URLs from `scam_dataset.json` to `/scan_links` and computes scikit-learn metrics (`classification_report`, `confusion_matrix`), while `test_qwen.py` performs a standalone connectivity probe.
