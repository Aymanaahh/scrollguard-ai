Single-process FastAPI application (`main.py`) exposing three HTTP endpoints: a health check at `GET /`, a single-item analyzer at `POST /analyze` returning an `AnalysisResponse` Pydantic model, and a batch endpoint at `POST /scan_links` accepting a `URLBatch`. Each classification follows a fixed two-stage pipeline: first `heuristics.heuristic_scan()` runs rule-based checks (free TLDs, typosquatting patterns, shortened URLs, scam keywords, missing HTTPS) to short-circuit with a non-Safe result; if the heuristic returns Safe, the request is forwarded to the OpenAI-compatible client configured against Alibaba DashScope's `/compatible-mode/v1` endpoint using the `qwen3.7-plus` model. A module-level `SYSTEM_PROMPT` enforces strict JSON output matching the response schema, and raw LLM responses are post-processed to strip markdown code fences before `json.loads`. Configuration is bootstrapped via `python-dotenv` loading `.env`, which must contain `DASHSCOPE_API_KEY`. CORS is enabled with wildcard origins to support browser-extension clients. Supporting scripts form a separate evaluation layer: `evaluate_engine.py` posts all URLs from `scam_dataset.json` to the running server and computes classification metrics via scikit-learn, while `test_qwen.py` performs a standalone connectivity probe.
