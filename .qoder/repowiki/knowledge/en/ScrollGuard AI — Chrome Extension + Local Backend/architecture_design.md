The repository composes two cooperating services: `extension/` runs in the browser as a Manifest V3 content script plus service worker, inspects visited pages and links, and forwards them over HTTP to `http://127.0.0.1:8000/scan_links`; `backend/` exposes a FastAPI/Uvicorn server on port 8000 that executes a two-stage pipeline (rule-based heuristics then Alibaba DashScope OpenAI-compatible call to `qwen3.7-plus`) and returns structured JSON risk scores of Safe, Suspicious, or Dangerous. The contract between children is the single `/scan_links` endpoint; data flow is strictly one-way (browser → service worker → FastAPI), and the backend has no awareness of the extension beyond this shared API surface. An evaluation script (`backend/evaluate_engine.py`) drives automated accuracy testing by hitting the same endpoints against a known dataset.
