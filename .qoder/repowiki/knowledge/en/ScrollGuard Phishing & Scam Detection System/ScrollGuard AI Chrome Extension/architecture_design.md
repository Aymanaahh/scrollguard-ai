Flat four-file Chrome Manifest V3 package declaring three execution contexts in `manifest.json`: a background service worker (`background.js`) acting as a privileged proxy to the FastAPI endpoint `http://127.0.0.1:8000/analyze`, a content script (`content.js`) injected at `document_idle` into `<all_urls>`, and a popup UI (`popup.html` + `popup.js`) bound via `action.default_popup`. The content script implements a three-layer pipeline — Layer 1 runs fast local heuristic checks against `URL_INDICATORS` (TLDs, shorteners, phishing path keywords, hyphen-heavy domain regex) and `TEXT_INDICATORS` (regexes for prize scams, crypto fraud, urgency, credential harvesting); Layer 2 calls `chrome.runtime.sendMessage({ action: 'analyzeUrl', url, text })` which the background service worker forwards via `fetch`; results are merged by `resolveSeverity` into one of three labels (`POTENTIAL THREAT` / `SUSPICIOUS` / `HIGH RISK`) and rendered as an inline-styled banner with sentinel ID `__scrollguard_banner__`. A `MutationObserver` on `document.body` with `{ childList: true, subtree: true }` continuously scrapes newly inserted `<a>` tags from SPAs, deduplicates via a `Set` of scanned URLs and a `WeakSet` of processed anchors, filters non-external links through `isValidExternalLink`, and marks flagged links inline with borders and badges. The popup is self-contained: it reads the active tab URL via `chrome.tabs.query`, posts JSON directly to the backend over HTTP, and renders `status`, `risk_score`, and `explanation` into styled cards. Dependency direction is strictly content-script → background-service-worker → backend; the popup bypasses the service worker and calls the backend directly.
